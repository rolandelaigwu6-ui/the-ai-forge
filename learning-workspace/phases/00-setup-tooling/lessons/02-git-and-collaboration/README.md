# Git & Collaboration

**Curriculum:** Phase 0, Lesson 02
**Status:** Ready to start

This is the next lesson in the official Phase 0 sequence. The source lesson is
[Git & Collaboration](https://github.com/rohitg00/ai-engineering-from-scratch/tree/main/phases/00-setup-and-tooling/02-git-and-collaboration).

It covers the working directory, staging area, local commits, remotes, pushing,
branches, `.gitignore`, and reading commit history. The lesson's exercises are
to push a small change on a branch, ignore model checkpoint files, and inspect
the repository history.

Earlier GPU/cloud notes were committed and pushed with agent assistance. That
records a real repository workflow, but it does not yet count as completing
this lesson's branch, `.gitignore`, and history exercises.
