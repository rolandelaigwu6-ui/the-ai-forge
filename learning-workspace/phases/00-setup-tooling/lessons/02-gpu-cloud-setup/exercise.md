## Suggested checks

1. Identify the machine and GPU from the cloud console or the machine's
   hardware tools.
2. Record operating system, driver, Python, and framework versions.
3. Ask the installed framework whether it can see the GPU. Save the output,
   including any error, without including account credentials.
4. Run a small workload and confirm that it uses the GPU. A visible GPU alone
   does not prove that the framework or workload is using it.
5. Stop or delete the cloud resource and confirm it is no longer running.

Commands depend on the provider, operating system, and installed framework, so
record the exact commands used alongside their output once known.
