# The AI Engineering Skills Map — Part 1

**Source:** Andrew Ng and DeepLearning.AI, “The AI Engineering Skills Map” (Part 1)

## Purpose

The map identifies skills developers should learn to build useful software in an AI-driven environment. It is based on analysis of more than 10,000 job postings, interviews with AI experts and hiring teams, surveys, and other online data. It describes broadly useful **AI engineering skills**, not just skills for people with the job title “AI engineer.”

## Four essential skill areas

1. **Build and deploy AI applications.** Understand AI building blocks such as LLMs, context engineering, retrieval-augmented generation (RAG), agentic workflows, machine learning, and deep learning. Because AI outputs are uncertain, use statistical measurement, steering, and governance to make systems more predictable. Run disciplined evaluations and error-analysis loops.

2. **Apply software engineering fundamentals.** Understand tradeoffs among cost, scalability, reliability, speed, security, and privacy. This knowledge informs choices about technology stacks, architecture, data stores, and testing. It also helps developers give coding agents the context and direction needed to make sound engineering decisions.

3. **Use coding agents effectively.** Develop a mental model of how agents work and where they fail. Manage context, choose when to plan or execute, decide how much to intervene, and provide verifiers or evaluations so agents can close loops. Work from a clear specification when useful, coordinate agents when appropriate, protect production systems, and keep adapting as tools and practices evolve.

4. **Shape the build.** Help decide what should be built, rather than only implementing a fully specified design. Bring product judgment and business and customer context to the work. Take ownership of opportunities, and choose when to make a quick MVP for user feedback versus when a problem calls for slower, more careful development.

## Thread running through the map

**Continuous learning** underlies all four areas. AI changes quickly, so developers need to keep learning and update their practices as new tools and better approaches emerge.

## Main takeaway

AI engineering combines building and evaluating uncertain AI systems, strong software judgment, effective use of coding agents, and the ability to shape projects around real needs. These skills are increasingly relevant across software roles, not only to people called AI engineers.
